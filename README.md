# 📦 StockFlow - Smart Inventory & Billing System

A full-stack Inventory & Billing System built using the MERN stack for small businesses. The application helps manage inventory, billing, sales, and business analytics through a modern and responsive interface.

## 🚀 Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- React Router
- Axios

## ✨ Features Completed

- MERN project setup
- Responsive Login Page
- Reusable Button Component
- Reusable Input Component
- Password Visibility Toggle
- Client-side Form Validation
- Live Validation

## 🚧 Features In Progress

- JWT Authentication
- Dashboard
- Product Management
- Billing System
- Invoice Generation
- Sales Analytics
- Profit & Loss Reports
